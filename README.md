# PromptCraft

[![CI](https://github.com/Dantheman23-coder/PromptCraft/actions/workflows/ci.yaml/badge.svg)](https://github.com/Dantheman23-coder/PromptCraft/actions/workflows/ci.yaml)
[![Docs](https://github.com/Dantheman23-coder/PromptCraft/actions/workflows/docs.yaml/badge.svg)](https://github.com/Dantheman23-coder/PromptCraft/actions/workflows/docs.yaml)

PromptCraft helps you turn raw thoughts into high-impact prompts for LLMs.

## Features
- Prompt rewriting and scoring
- Semantic and keyword search
- Multiple gameplay modes
- CLI and Python API

## Quickstart
```bash
pip install -e .[dev]
promptcraft rewrite "write me a haiku" --model gpt-4o
```
